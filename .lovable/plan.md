# Diverse Resilience Systems Website

Build a polished company website using the uploaded profile and DRS logo, with a consistent, mobile-friendly navigation and distinct Home, About, Team, Projects, Testimonials, Blog, and Contact pages. Use the brand’s deep navy, vivid blue, orange, and leaf green, with clean editorial typography and restrained motion.

Team and blog cards will be keyboard-accessible and open fuller details. Projects will reflect assignments documented in the profile. The testimonials page will be ready for approved client quotes without inventing endorsements. Contact details and services will come from the profile.

## Technical details

Use TanStack Start file-based routes, a shared site shell, semantic design tokens, and the existing UI components. Add the provided logo via the project asset flow and create its square favicon. Verify all routes, card interactions, mobile layout, existing routing tests, and preview diagnostics.
